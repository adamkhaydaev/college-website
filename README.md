# KUD College Website

Официальный многостраничный сайт колледжа, разработанный для публикации информации об образовательной организации, поступлении, учебном процессе и мероприятиях.

🌐 **Рабочая версия:** https://kud-college.ru

## О проекте

Проект представляет собой полноценный информационный сайт колледжа.

Основная задача — создать удобный ресурс, на котором абитуриенты, студенты и родители могут быстро найти необходимую информацию: сведения о колледже, направления подготовки, расписание, объявления и другие материалы.

Проект используется как реальный сайт образовательной организации.

## Возможности

- многостраничная структура сайта;
- адаптивная вёрстка;
- навигация между разделами;
- страницы для абитуриентов и студентов;
- размещение новостей и объявлений;
- раздел с расписанием;
- формы обратной связи;
- интерактивные элементы на JavaScript;
- отображение информации об образовательной организации;
- адаптация интерфейса для разных размеров экрана.

## Технологии
