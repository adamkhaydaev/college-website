# College Website

Официальный многостраничный сайт колледжа, разработанный для публикации информации об образовательной организации, поступлении, учебном процессе, расписании и мероприятиях.

🌐 **Рабочая версия:** https://kud-college.ru

## О проекте

`College Website` — реальный информационный сайт образовательной организации.

Сайт предназначен для абитуриентов, студентов, родителей и сотрудников колледжа. Основная задача проекта — предоставить удобный доступ к важной информации и объединить основные разделы колледжа в одном веб-ресурсе.

Проект опубликован и используется как действующий сайт колледжа.

## Основные возможности

- многостраничная структура;
- адаптивная вёрстка;
- разделы для абитуриентов и студентов;
- новости и объявления;
- информация об образовательной организации;
- страницы с расписанием;
- формы обратной связи;
- интерактивные элементы на JavaScript;
- поддержка мобильных устройств;
- отдельные PHP-обработчики для форм.
